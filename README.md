# مساحة الاعتماد المدرسي — القشرة

واجهة ثابتة (static) لتعبئة سجلات الاعتماد المدرسي وشواهدها، وإجراء أدوات دورة
التقويم الذاتي العشر، ومتابعة الخطة التحسينية — **بلا خادم ولا قاعدة بيانات ولا اشتراك**.

## المبدأ

هذا المستودع **لا يحوي أي بيانات مدرسية**. كل البيانات تعيش في مجلد المدرسة على
OneDrive، ويختاره المستخدم مرّة واحدة من داخل المتصفّح عبر
[File System Access API](https://developer.mozilla.org/docs/Web/API/File_System_API).
لا يمرّ شيء بأي خادم، ولا يُخزَّن أي اسم مستخدم أو كلمة مرور.

## المتطلّبات

- **Microsoft Edge** أو **Google Chrome** على حاسب ويندوز.
- تطبيق مزامنة OneDrive مثبَّت، ومجلد المدرسة مُضاف بـ«إضافة اختصار إلى ملفاتي».
- ⚠️ لا يعمل على سفاري ولا على أجهزة iPad.

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | الشاشات: اتصال ← هوية ← لوحة ← سجل ← أدوات ← خطة تحسينية |
| `storage.js` | محوّل التخزين: مجلد محلي (FSA) أو HTTP للاختبار |
| `record.js` | محرّك عرض السجلات — 32 نوع حقل و17 نوع عمود |
| `tools.js` | أدوات التقويم الذاتي العشر والتجميع على مؤشرات ETEC |
| `print.js` | الطباعة بكليشة ابن خلدون متكرّرة على كل ورقة |
| `استبانة.html` | صفحة الاستبانة العامة لأولياء الأمور والطلاب والمعلمين |
| `survey.js` | ترميز الاستجابات ونقلها بالواتساب أو للنقطة السحابية |
| `cloudflare-worker.js` | نقطة استقبال مجانية اختيارية — التنصيب موثَّق داخل الملف |
| `_تغطية.html` | صفحة فحص: ترسم كل قوالب حزمة وتعدّ ما لا معالج له |

## التشغيل محليًا

```bash
python3 -m http.server 8788
# ثم افتح http://127.0.0.1:8788/index.html
```

للفحص الآلي بمصدر HTTP بدل المجلد: `index.html?data=/مسار/الحزمة`

## نشر الاستبانات — مساران والمدرسة تختار

الصفحة الثابتة تستطيع أن تُرسِل رابطًا ولا تستطيع أن تستقبل ردًّا من ولي أمر لا
حساب له. فالمسارَان:

1. **واتساب (بلا أي بنية تحتية)** — يعبّئ ولي الأمر، فتُفتح له رسالة جاهزة برمز
   قصير يرسلها بنقرة. والمدرسة تلصق الرسائل في شاشة الأداة فتُستخرج وتُحفظ.
2. **نقطة سحابية مجانية (اختيارية)** — Cloudflare Worker على الخطة المجانية،
   فتصل الاستجابة مباشرة كما في المنصة. التنصيب في `cloudflare-worker.js`.

إن ضُبط المساران عمل السحابي أولًا، ويسقط للواتساب إن تعذّر.
